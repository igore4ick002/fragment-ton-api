# Changelog

## 0.1.4

- Added authentication, error code, and example scenario docs.
- Added GitHub Actions for ruff, pytest, build, twine check, and gitleaks.
- Added pytest async tests for gift purchase and delivery flow.
- Added public result types: `PaymentResult`, `GiftItem`, `CollectionItem`, and `BalanceResult`.
- Added typed `get_balance()` helper.
- Added ruff configuration and development dependencies.

## 0.1.3

- Added ready-to-run examples for Stars, Premium gifts, gift listing, gift purchase, and gift transfer.
- Added unit tests for catalog parsing and result format helpers.
- Added `py.typed` for type checker support.
- Added typed Fragment exception classes and structured result helpers.
- Added `docs/api.md` API reference.

## 0.1.2

- Rewrote README documentation in English.
- Added GitHub security and contributing files.

## 0.1.1

- Added project links for PyPI: Homepage, Documentation, and Issues.
- Added maintainer name and email metadata.
- Expanded usage documentation for Stars, Premium gifts, collectible gifts, transfers, and TON balance.

## 0.1.0
